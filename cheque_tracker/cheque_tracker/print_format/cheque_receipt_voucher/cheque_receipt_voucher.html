Clone of EEI's approved Sales Invoice format (EEI_PRINT_DESIGN_REFERENCE §5): same tokens, same table-based layout, same titlebar / info-grid / totals / words / ack / signature sequence. No flexbox or grid anywhere — the approved formats are table-based on purpose so the desk print view and the PDF engine agree, and this one keeps that. The Cairo web-font pulled in by the approved formats is deliberately dropped: PDF rendering runs with no network, and a blocked font request is a stalled voucher. The font stack is unchanged, so Cairo is still used where installed. Amount in words comes from the app's Arabic tafqeet helper, which reaches Jinja only through the `jinja.methods` hook. Until that hook entry exists the global is simply undefined, so every call site is guarded and falls back to the figure — a receipt that prints without words is recoverable, a 500 is not. -#}
